# MMA Stats Compose 🥊

A simple **Jetpack Compose-based Android application** that displays MMA statistics and includes a **multi-language settings screen** with unit preferences.

## 📱 Features

- 🌐 Multi-language support (English 🇬🇧 / Turkish 🇹🇷)
- ⚖️ Weight unit selection (kg / lbs)
- 📏 Height unit selection (cm / inches)
- Built with modern **Jetpack Compose** UI
- Clean architecture with **ViewModel** and **Hilt (Dependency Injection)**

---

## 🚀 Tech Stack

- **Kotlin**
- **Jetpack Compose**
- **Material 3**
- **Hilt (Dagger)**
- **StateFlow**
- **MVVM Architecture**
